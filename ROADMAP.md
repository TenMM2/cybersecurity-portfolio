# 🗺️ Roadmap — 18 meses hacia ciberseguridad remota

> Actualiza las fechas reales al ir completando cada hito. Marca [x] cuando termines algo.

**Fecha clave:** incorporación al puesto prevista entre el **1 y el 6 de enero** (2027). Las Fases 1-2 de abajo son el objetivo a cubrir *antes* de esa fecha o en paralelo a los primeros meses del puesto.

## 🌍 Pista paralela — Inglés (en marcha ya, 3h/día)
El inglés es tan crítico como las certificaciones para trabajo remoto internacional — la mayoría de ofertas nómadas lo piden B2+ mínimo.
- [ ] Nivel actual evaluado (test online tipo Cambridge/EF — anota el resultado aquí)
- [ ] Objetivo: B2 sólido antes de aplicar a puestos remotos internacionales (~mes 6-9)
- [ ] Practicar específicamente vocabulario técnico de seguridad en inglés (los cursos de TryHackMe/Security+ ya ayudan con esto de forma gratuita)
- [ ] Certificación formal opcional (EF SET gratis, o Cambridge/IELTS si un empleador la pide)

## Fase 1 — Fundamentos (Mes 1-3, objetivo: antes/justo al empezar en enero)

- [ ] TryHackMe — ruta "Cyber Security 101"

## Fase 2 — Certificación clave (Mes 3-6)
- [ ] Estudio CompTIA Security+ (libro/curso + práctica)
- [ ] Examen CompTIA Security+ aprobado
- [ ] Subir evidencia en [CERTIFICATIONS.md](CERTIFICATIONS.md)

## Fase 3 — Especialización (Mes 6-12)
Elegir UNA rama según intereses tras la Fase 2:

**Opción A — Ofensivo (pentesting)**
- [ ] eJPT
- [ ] 10+ máquinas en HackTheBox con write-up documentado
- [ ] Participar en 2-3 CTFs (CTFtime.org)

**Opción B — Defensivo (SOC / Blue Team)**
- [ ] Blue Team Level 1 (BTL1)
- [ ] Splunk Fundamentals (gratis)
- [ ] Montar un SIEM casero (Wazuh) y documentarlo

**Opción C — Cloud Security**
- [ ] AWS Certified Cloud Practitioner
- [ ] AWS Security Specialty (o AZ-500 si usas Azure)
- [ ] Proyecto: asegurar una infraestructura cloud de juguete (IAM, VPC, logging)

## Fase 4 — Home lab y evidencia práctica (en paralelo, Mes 6-12)
- [ ] Montar [GOAD (Game of Active Directory)](https://github.com/Orange-Cyberdefense/GOAD) en local
- [ ] Documentar 3 ataques + mitigaciones en `homelab/`
- [x] Publicar al menos 1 script propio en `scripts/` (ej. escáner de puertos en Python)

## Fase 5 — Búsqueda activa (Mes 12-18)
- [ ] CV actualizado con certificaciones + portfolio
- [ ] Perfil LinkedIn optimizado (ciberseguridad como foco)
- [ ] Aplicar a puestos junior 100% remotos (SOC Analyst / Security Specialist / Cloud Security Junior)
- [ ] Objetivo: primer contrato remoto internacional
