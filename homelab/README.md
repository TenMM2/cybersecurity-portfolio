# 🏠 Home Lab

Documentación del laboratorio casero de Active Directory vulnerable, usando [GOAD (Game of Active Directory)](https://github.com/Orange-Cyberdefense/GOAD).

Como ya tienes experiencia profesional real con Active Directory (Grupo Solutio), este es tu mayor diferenciador frente a otros candidatos junior: puedes hablar tanto del lado "admin" como del lado "atacante/defensor" del mismo sistema.

## Checklist de montaje
- [ ] VirtualBox / Proxmox instalado
- [ ] GOAD desplegado (varios Windows Server + controlador de dominio)
- [ ] Kali Linux como máquina de ataque
- [ ] Primer ataque documentado (ej. Kerberoasting, AS-REP Roasting, etc.)
- [ ] Mitigación de cada ataque documentada
